# Retro — sweep-the-open-issue-backlog-fix-the

## What was built

Eighteen open issues landed as one run of fourteen tasks in three waves: the follow-ups file gained an honest wave number and an identity (#53, #44); the spec gate's failure paths were closed with a checked event write, a reason on the receipt, a hash on the findings file and a `review-record` doctor check (#43); the retro inputs now count every review and time every dispatched attempt (#23, #25); `status`, `unlock` and the goal-assessor's citations became stricter and better-hinted (#33, #8, #24); the PR is written from the run instead of `--fill` and `branch_finish` no longer recommends a disabled merge (#36, #26); task briefs name the spec by path (#31); the copilot reviewer runs without custom instructions (#49); the two polish checklists (#45, #51) and four documentation fixes (#54, #37, #35, #18) landed alongside. The goal assessor judged all thirteen goals `achieved` at `770ba26`, and verification at that SHA passed every one of the plan's verify commands, including `go test ./... -race`, `golangci-lint run ./...` and `task hosts:check`.

## What went well / what did not

- **Every goal achieved, verification green, nothing overridden.** `verify.passed` is true with no failed commands; the goal record has thirteen `achieved` verdicts and no waived goal. The citation check this run added (#24) accepted the assessor's own reply on the first try.
- **Wave 2 closed on its first attempt** in 11m46s (dispatched 01:15:47Z, committed 01:27:33Z): one task (T9), six lenses, three confirmed candidates, no rework.
- **Wave 0 needed three attempts and wave 1 four.** Eight of fourteen tasks were retried: T1 ×2, T4 ×3, T5 ×2, T6 ×2, T8 ×2, T12 ×3, T13 ×4, T14 ×2. The inputs carry a timing only for the attempt that committed — wave 0 attempt 3 in 18m53s (20:14:52Z → 20:33:46Z), wave 1 attempt 4 in 19m15s (00:56:22Z → 01:15:37Z) — so the four-plus hours between wave 0's commit and wave 1's are invisible here. That is exactly #25, which this run fixed; the binary that drove the run (`0.0.0-dev`, built before the sweep) still writes the old shape, which is also why `review_findings` is 5 (the surviving close records only) and the `gate_review_findings` / `task_review_findings` split is absent.
- **Two tasks were waived, both on grounds the tree disproves.** T5 (#24) was rejected for a missing `//nolint:gosec` annotation that the linters would not accept in any placement — gosec does not fire at that site and `nolintlint` reports the directive unused — and the reviewer's final objection was to a comment that named the token. T8 (#54/#35/#18 docs) was rejected because "the diff also contains substantial unrelated documentation changes": the reviewer was reading the wave diff, and the other tasks' documentation edits were counted against T8. Both tasks' work is in the tree and is what G6 and G12 were judged `achieved` on.
- **The cross-vendor reviewer contradicted itself across attempts.** For T12 the wave-1 attempt-2 verifier confirmed that quoting the body path "contradicts the task's literal template" (verify.s1.a2 c5); the attempt-3 verifier then confirmed that leaving it unquoted is a defect (c7, follow-up 23 below). T13 took four attempts over wording the reviewer alternately required and rejected. Two of the wave-1 backend reviews also timed out and were retried at the `review_error` gate.
- **Internal review: 57 candidates, 46 confirmed (81%), 11 false positives, 5 unattributed to a task, 0 scoped passes, 1 overlap with the cross-vendor reviewer.** Per lens — consistency 13/13, tests 17/17, simplicity 3/3, correctness 1/1, docs 10/18, intent 2/5. Every lens confirmed at least one finding, so none is a removal candidate from `review.lenses` on this run's evidence; docs (8 false positives) and intent (3) are the noisy ones, and consistency and tests carry most of the confirmed volume. The single overlap says the lenses and the cross-vendor reviewer are looking at different things, which is the intended division rather than a problem.
- **The blind task review cannot see carried findings.** Wave-0 and wave-1 rework rounds repeated "out of scope" objections that the previous attempt had already answered; the lens findings carried into the follow-ups (26 of the 27 below are `internal`) never reached the reviewer that graded the retry.
