# Review: spec — rework

Two blocking factual mismatches would leave the primary defects unfixed: close records do not mark waived task results as waived, and the proposed issue parser ignores the repository's supported issue-URL topic form. The assumptions table is present and most goals otherwise track the spec.

- **blocking** spec.md:110 — The close-record fallback excludes the waived tasks it is intended to recover: `takt waive` changes only `state.Tasks[i].Status`; `carryForward` copies the retired `wave.TaskResult` unchanged, preserving its earlier `failed`, `blocked`, or `rework` status. Therefore filtering close-record results to `done` or `waived` does not produce the claimed complete slice and can omit precisely the waived tasks behind G1. Revise the derivation source or rule and make the golden model the statuses actually persisted by the close path.
- **blocking** spec.md:143 — The issue parser misses supported issue-link topics: The codebase explicitly supports topics containing `/issues/<n>` (`deriveSlug` handles them), and the design's canonical `state.Topic` example is a full GitHub issue URL without a `#N` token. Parsing only `#\d+\b` therefore omits `## Issues` for a supported run started from an issue, contradicting §1.2, §4, and G4. Specify URL handling, same- versus cross-repository closing syntax, de-duplication across forms, and corresponding tests. The claim that this regex excludes CSS colours is also false for numeric colours such as `#123`.
- **minor** spec.md:316 — Substitution multiplicity is described inconsistently: Section 2.3 permits substitutions declared as repeated, while the assumptions table says every substitution not matching exactly once errors. State one contract, preferably an explicit expected multiplicity per substitution, so generator tests and implementation use the same rule.
- **minor** goals.md:15 — G7's global wording conflicts with its evidence boundary: The goal says no design paragraph names `plainOp` or the stale last-commit claim, but this run's own spec necessarily contains both while the evidence explicitly exempts run bundles. Scope the assertion to production code comments and the canonical design document.
